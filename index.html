Open a .crt file, select it, then Load & run. Alt + R restarts the cartridge.
Supported hardware: Normal 8K / 16K / Ultimax, Ocean, Magic Desk, EasyFlash and GMod2 (512 KB ROM plus 2 KB EEPROM). Other CRT hardware types show a specific error.
Bank selection, control registers and cartridge RAM are included in save states. GMod2 EEPROM saves are included in states and stored per cartridge when browser storage is available. Flash programming and freezer cartridges are not implemented.
Library → Drives & tape → Eject from drive detaches an inserted cartridge and resets the C64. Disk ejection does not reset. Starting a disk or tape program also detaches it.


MOSaiC64 0.6.6
Original JavaScript CPU, VIC-II, SID, file loaders, drive model and interface. No downloaded emulator code, libraries or ROMs.
PAL video, three SID voices and hardware drives 8–11. Both performance profiles keep the same emulated timing. Unusual fastloaders, raster tricks and analog sound still have the existing compatibility limitations.
Runs offline. On mobile, open the HTML in a browser that executes local files. Where native fullscreen is unavailable, immersive mode fills the browser viewport.
